# GH3 visual history

This file preserves the notes from before the runtime fixes. Version-specific behavior and old commands can differ from the current build. See [README.md](../README.md) for current use.

This mod uses gameplay art extracted from the owner's BetterGH3 PC copy. It runs with the isolated Linux Clone Hero v1.1.0.6142 copy and MelonLoader 0.7.3.

The current skin uses a black highway with GH3 rail art and a revised camera. GH3 gems stay at Clone Hero's note depth instead of being pushed forward and shrunk. Star gems use a larger sprite size than regular gems. Clone Hero keeps its moving beat-line sprites and places them above the highway surface. In a note-free 1600 × 900 test, the lines remain visible down to the fret row. Clone Hero also keeps its original fret buttons, fret positions, strings, and button animation. The GH3 lower-left graphic is absent. The older version notes below describe earlier builds.

The ready banner plays once when the displayed meter reaches 50%. It replays 126 frames extracted from the owner's GH3 recording at 60 fps, including the text, stars, light sweep, and lower lightning. It disappears after 2.1 seconds while the meter remains charged. It can play again after the meter falls below 50% and then reaches 50% again. Run `uv run --with pillow --with numpy ./prepare-ready-animation.py` with `gh3-long-star-power-1600x900.mp4` in the project directory to regenerate these assets. The lower lightning uses a color and frame-difference mask because the source is a gameplay recording, not a transparent effect asset.

The user-requested original Clone Hero frets and omitted lower-left GH3 graphic also prevent a whole-frame pixel match.

Set `GH3_SKIN_FORCE_POWER=0.5 GH3_SKIN_FORCE_POWER_AT_COMBO=20 GH3_SKIN_FORCE_ROCK=0.8` before `record-preview.sh` to repeat the delayed ready-banner test. ## Code and checks

`src/Gh3Skin.cs` controls the gameplay-scene lifecycle. `SkinOptions` reads test overrides, `GameplayStateReader` reads Clone Hero values, and `GameplaySpriteRenderer` replaces world sprites. `SkinAssets` loads art, while `GameplayHud` draws the score, rock meter, bulbs, streak counter, and ready animation. `HudTuning` loads measured layout values. `PreviewCapture` handles test screenshots. The source art and tuned coordinates are not changed by this code split.

Run the logic checks with `dotnet run --project tests/SkinLogic.Tests.csproj -c Release`. Build the mod with `bash install.sh`; it needs the isolated Clone Hero installation. To check the visual output, use `record-preview.sh` with the same chart and environment values before and after a change. Do not treat the forced visual meter as earned Star Power.
